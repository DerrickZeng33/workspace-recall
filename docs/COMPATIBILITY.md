# Compatibility Matrix

This document tracks compatibility test results for Workspace Recall.

Compatibility results are **evidence snapshots**, not guarantees of support. A result only describes the specific application version, file format, environment, and test conditions that were checked. Future versions or different configurations may behave differently.

## Privacy Rules

All compatibility testing must use fictional data only.

Do not include:

- Personal information
- Real filenames
- Real filesystem paths
- Private screenshots
- Private document contents

Use fictional examples when documenting tests, such as:

- `C:\Users\Test\Documents\example.pdf`
- `C:\Users\Test\Documents\sample.txt`

## Status Definitions

### Capture Status

- **File identified**  
  The application file or document was identified successfully.

- **Program only**  
  The application was identified, but a specific file/document was not captured.

- **Needs review**  
  The result requires further investigation.

- **Excluded**  
  The application or format is intentionally not supported or tested.
