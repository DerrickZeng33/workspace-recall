# Code of Conduct

Workspace Recall welcomes respectful, constructive participation.

## Expected behavior

- Discuss ideas and evidence rather than attacking people.
- Give feedback that is specific, relevant, and actionable.
- Respect different experience levels, backgrounds, and viewpoints.
- Protect other people's privacy. Do not publish personal information, private
  workspace data, or sensitive security details.
- Accept moderation decisions and move on when a conversation is closed.

## Unacceptable behavior

- Harassment, threats, discrimination, sexualized attention, or personal
  attacks.
- Trolling, sustained disruption, spam, or coordinated manipulation.
- Publishing or threatening to publish another person's private information.
- Sharing malicious code or exploit details outside the private security
  process.
- Impersonation or misleading claims about project maintainers or users.

## Scope and enforcement

This code applies to repository Issues, Discussions, pull requests, reviews,
and other project-managed spaces. Maintainers may edit, hide, lock, reject, or
remove contributions and may restrict participation when necessary.

Do not publish sensitive evidence in a conduct report. Use GitHub's
[Report abuse](https://support.github.com/contact/report-abuse) process for
confidential reports about activity on GitHub. Report vulnerabilities through
the private process in [SECURITY.md](SECURITY.md).

The project intentionally publishes no personal maintainer email or phone
number.
